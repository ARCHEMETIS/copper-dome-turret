## 📓 วิธีเปิดสมุดบันทึก (notebook)

**ทาง VS Code (แนะนำ ถ้าใช้ VS Code อยู่แล้ว):**
1. เปิดไฟล์ `.ipynb` ในโฟลเดอร์ `learn/notebooks/` ได้เลย (VS Code รองรับในตัว ไม่ต้องลงอะไรเพิ่มถ้ามี Jupyter extension)

3. กด **Shift+Enter** ที่แต่ละเซลล์เพื่อรันทีละอัน

**ทางเบราว์เซอร์ (ถ้าไม่ได้ใช้ VS Code):**
```powershell
cd "C:\Users\Pc\Desktop\Project III"
venv\Scripts\python.exe -m notebook learn\notebooks
```
จะเปิดแท็บเบราว์เซอร์ขึ้นมา คลิกเลือกไฟล์บทเรียนที่จะเรียน แล้วกด Shift+Enter ทีละเซลล์เหมือนกัน

## 📚 ลำดับบทเรียน (ทำตามลำดับ ห้ามข้าม แต่ละบทต่อยอดบทก่อนหน้า)

| บท | ไฟล์ | ได้เรียนรู้ | เชื่อมกับโปรเจคจริงยังไง |
|---|---|---|---|
| 0 | `00_python_numpy_basics.ipynb` | ตัวแปร, list, numpy array, indexing `[y,x]` | พื้นฐานที่ทุกบทถัดไปใช้ — **เริ่มที่นี่ถ้าไม่เคยเขียนโค้ดมาก่อน** |
| 1 | `01_camera_and_images.ipynb` | เปิดกล้อง, ภาพ = numpy array, กับดัก BGR vs RGB | โครงของทุกโปรแกรม vision |
| 2 | `02_color_and_hsv.ipynb` | ทำไมต้องใช้ HSV, จูนช่วงสีด้วยแถบเลื่อนแบบอินเทอร์แอคทีฟ | ได้ค่าสีจริงไปใส่ `src/config.py` |
| 3 | `03_tracking_and_aiming.ipynb` | contour → กรอบ → จุดกลาง → **error การเล็ง** | คือ `src/aiming.py` ฉบับอธิบายละเอียด — หัวใจของป้อม |
| 4 | `04_distance_measurement.ipynb` | วัดระยะจากขนาดวัตถุ + calibrate ด้วยตัวเอง (มีเฉลยตรวจคำตอบ) | คือ `src/ranging.py` + `tools/calibrate_focal.py` เป๊ะ |
| 5 | `05_yolo_intro.ipynb` | YOLO ตรวจจับ 80 วัตถุสำเร็จรูป, ทำไมต้องเทรนเอง | ทางหลักของโปรเจค (`src/detector.py`) |

ทุกบทเขียนให้ **รันได้แม้ไม่มีกล้อง** (สลับไปใช้ "ภาพจำลองสนาม" ให้อัตโนมัติ) และมีเซลล์โบนัสให้ลองกับกล้องจริงของตัวเองท้ายบท

## แนวคิดรวม: ภาพจากกล้อง → ยิงโดนเป้า ได้ยังไง

```
เฟรมภาพ ──(บท2: แยกสี / บท5: YOLO)──► กรอบรอบวัตถุ
   กรอบ ──(บท3)──► จุดกลางวัตถุ ─ เทียบกลางภาพ ─► error → สั่งป้อมหมุน
   กรอบ ──(บท4)──► ความกว้าง px ──► ระยะ (mm) ──► ความแรงล้อยิง
```

เข้าใจครบ 6 บทนี้ (0-5) = เข้าใจฝั่ง vision ของโปรเจคทั้งหมดแล้ว เหลือแค่ต่อ Arduino

## ปัญหาที่อาจเจอ

- **เปิดกล้องไม่ได้**: แก้เลข `index` ใน `เปิดกล้องหรือภาพจำลอง(index=0)` เป็น 1 หรือ 2 / เช็คว่าไม่มีแอปอื่นใช้กล้องอยู่ / เช็ค Windows Settings > Privacy > Camera ว่าอนุญาตแอปเดสก์ท็อป
- **ไม่มีกล้องโน้ตบุ๊ก**: ลงแอป DroidCam บนมือถือ + โปรแกรม DroidCam Client บน PC (ฟรี) มือถือจะกลายเป็น webcam — หรือข้ามไปก่อนก็ได้ ทุกบทมี "ภาพจำลองสนาม" ให้ใช้แทน
- **VS Code ไม่มีตัวเลือก Jupyter/ipynb**: ติดตั้ง extension "Jupyter" (โดย Microsoft) จาก Extensions marketplace
- **กด Select Kernel แล้วไม่เห็น "Python (Copper Dome)"**: เลือก "Select Another Kernel" → "Existing Jupyter Server" หรือชี้ path ไปที่ `venv\Scripts\python.exe` ตรงๆ
- **บทที่ 5 (YOLO) ช้า/โหลดนาน**: ปกติบน CPU และครั้งแรกต้องโหลดไฟล์โมเดลผ่านเน็ต หลังจากนั้นจะเร็วขึ้นและใช้ออฟไลน์ได้
