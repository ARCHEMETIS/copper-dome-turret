# บทเรียน Vision — ฝึกจับภาพวัตถุโดยไม่ต้องมีอุปกรณ์ Arduino

ใช้แค่กล้องโน้ตบุ๊ก (หรือมือถือผ่านแอป DroidCam ก็ได้) + วัตถุสีสดสักชิ้น เช่น ขวดน้ำเขียว ฝาขวด ผลไม้ ตุ๊กตา

## วิธีรัน

เปิด PowerShell ในโฟลเดอร์ `Project III` แล้ว:

```powershell
venv\Scripts\python.exe learn\01_camera.py
```

(เปลี่ยนเลขไฟล์ตามบทที่จะเรียน — **ห้ามใช้คำสั่ง `python` เฉยๆ** เพราะจะไปเรียก Python ของ MSYS2 ที่ใช้กับ OpenCV ไม่ได้ ต้องใช้ `venv\Scripts\python.exe` เสมอ)

## ลำดับบทเรียน (เรียงจากง่ายไปยาก ทุกบทต่อยอดกัน)

| บท | ไฟล์ | ได้เรียนรู้ | เชื่อมกับโปรเจคจริงยังไง |
|---|---|---|---|
| 1 | `01_camera.py` | เปิดกล้อง, ภาพ = numpy array, สี BGR | โครงของทุกโปรแกรม vision |
| 2 | `02_hsv_tuner.py` | จูนช่วงสี HSV ด้วยแถบเลื่อน, mask คืออะไร | ได้ค่าสีจริงไปใส่ `config.py` (ไดโนเขียว) |
| 3 | `03_track_object.py` | contour → กรอบ → จุดกลาง → **error การเล็ง** | คือ `aiming.py` ฉบับย่อ — หัวใจของป้อม |
| 4 | `04_distance.py` | วัดระยะจากขนาดวัตถุ + calibrate focal | คือ `ranging.py` + `calibrate_focal.py` เป๊ะ |
| 5 | `05_yolo_demo.py` | YOLO ตรวจจับ 80 วัตถุสำเร็จรูป | ทางหลักของโปรเจค (แต่ต้องเทรนตุ๊กตาเอง) |

## แนวคิดรวม: ภาพจากกล้อง → ยิงโดนเป้า ได้ยังไง

```
เฟรมภาพ ──(บท2: แยกสี / บท5: YOLO)──► กรอบรอบวัตถุ
   กรอบ ──(บท3)──► จุดกลางวัตถุ ─ เทียบกลางภาพ ─► error → สั่งป้อมหมุน
   กรอบ ──(บท4)──► ความกว้าง px ──► ระยะ (mm) ──► ความแรงล้อยิง
```

เข้าใจครบ 5 บทนี้ = เข้าใจฝั่ง vision ของโปรเจคทั้งหมดแล้ว เหลือแค่ต่อ Arduino

## ปัญหาที่อาจเจอ

- **เปิดกล้องไม่ได้**: แก้เลขใน `VideoCapture(0, ...)` เป็น 1 หรือ 2 / เช็คว่าไม่มีแอปอื่นใช้กล้องอยู่ / เช็ค Windows Settings > Privacy > Camera ว่าอนุญาตแอปเดสก์ท็อป
- **ไม่มีกล้องโน้ตบุ๊ก**: ลงแอป DroidCam บนมือถือ + โปรแกรม DroidCam Client บน PC (ฟรี) มือถือจะกลายเป็น webcam
- **หน้าต่างภาพไม่ขึ้น**: อย่ารันใน background — ต้องรันใน PowerShell ปกติแล้วหน้าต่างจะเด้งขึ้นมา กด q ในหน้าต่างภาพเพื่อออก
- **บทที่ 5 ช้า**: ปกติบน CPU — ดูเคล็ดลับย่อภาพท้ายไฟล์
