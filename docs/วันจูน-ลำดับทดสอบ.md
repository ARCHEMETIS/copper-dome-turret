> **หลักการเดียวของเอกสารนี้: เพิ่มทีละอย่าง** ทุกขั้นเพิ่มของใหม่แค่ชิ้นเดียว
> พังตรงไหนจะได้รู้ทันทีว่าเป็นเพราะอะไร — ถ้าเสียบทุกอย่างแล้วรันตัวเต็มเลย
> พอไม่ทำงานจะแยกไม่ออกว่ากล้อง/บอร์ด/สาย/โค้ด/ทิศ อันไหนผิด
>
> ปุ่มกดอยู่ที่ **Desktop → โฟลเดอร์ `Copper Dome`** ดับเบิลคลิกตามเลข 0→4
> รายละเอียดการจูนเชิงลึกอยู่ `docs/aiming-tuning.md` (เอกสารนี้คือลำดับ + ปุ่ม)

## ก่อนเริ่ม — เตรียมของ

- [ ] Arduino ต่อสาย USB + **อัปโหลด StandardFirmata ไว้แล้ว** (ทำครั้งเดียวตลอดชีพ ไม่ต้องทำซ้ำทุกวัน)
- [ ] iPhone เปิดแอป Camo + **Auto-Lock → Never** (จอดับ = ภาพหยุดส่งทันที)
- [ ] Camo Studio เปิดอยู่บนคอม และ**เห็นภาพจริง** (ไม่ใช่จอดำ/โหมด Card)
- [ ] ไฟเลี้ยงมอเตอร์แยกจาก USB (L298N) — แบตพอ ไม่งั้นล้อออกตัวแล้วบอร์ดดับ
- [ ] **กล้องยึดแน่นกับลำกล้อง** ขยับด้วยมือแล้วไม่คลอน ← ข้อนี้สำคัญที่สุด กล้องขยับ = zero เพี้ยนหมด จูนเท่าไหร่ก็ไม่นิ่ง
- [ ] ลูกไม้อย่างน้อย 10 ลูก + พื้นที่โล่งหน้าปากกระบอก
- [ ] ตุ๊กตา 3 ตัว + ที่วางระดับโต๊ะ ระยะ 1.5–2.4 ม.

## 0️⃣ `0-เช็คระบบ.bat` — ไม่ต้องต่ออะไรเลย
พิสูจน์ว่าโค้ด+โมเดลยังดีอยู่ ก่อนไปโทษฮาร์ดแวร์

✅ **ผ่านเมื่อ** ขึ้น `SMOKE TEST PASSED — ยิงโดน 9/9`
❌ **ไม่ผ่าน** → หยุด อย่าเพิ่งต่อฮาร์ดแวร์ ส่ง error มาให้ผมดู

## 1️⃣ `1-ทดสอบป้อม.bat` — ต่อ Arduino อย่างเดียว (ยังไม่ต้องมีกล้อง)
พิสูจน์ servo + มอเตอร์ + สาย ว่าทำงาน **ก่อน**เอาภาพมาเกี่ยว

| ทำ | ต้องได้ |
|---|---|
| กด `a` / `d` | ป้อมหมุนซ้าย/ขวา ทีละ 5° ไม่สั่น ไม่ครืดคราด |
| กด `w` / `s` | ก้ม/เงย ได้ ไม่มีเสียงเฟืองขบ |
| กด `c` | กลับกลางลำ |
| กด `f` แล้ว `g` | **ล้อหมุนแล้วหยุด — ดูทิศทางล้อว่าจะพ่นลูกออก "ข้างหน้า" ไม่ใช่ดูดเข้า** |
| กด `t` (ใส่ลูก) | ยิงออกจริง |

⚠️ ถ้าล้อหมุนผิดทาง = สลับ `IN3`/`IN4` ใน `hardware.py` (มีคอมเมนต์บอกไว้บรรทัด 63)
⚠️ ถ้าบอร์ดดับตอนล้อออกตัว = ไฟไม่พอ ไม่ใช่โค้ด (soft-start ช่วยแล้วแต่ไม่ปาฏิหาริย์)

**🎯 ตรงนี้เก็บค่าจริง 2 ตัวที่ยัง TODO อยู่:**
- ยิงสัก 5 นัด จับเวลาว่าล้อต้องหมุนกี่วิถึงเสียงนิ่ง → `FLYWHEEL_SPINUP_S` (ตอนนี้เดา 1.5)
- `FLYWHEEL_FEED_WINDOW_S` ตอนนี้ 2.5 วิ **ทันหย่อนไหม?** ไม่ทันบอกได้ ผมเพิ่มให้

## 2️⃣ `2-ทดสอบกล้อง.bat` — ต่อกล้องอย่างเดียว (ถอด Arduino ได้)
พิสูจน์ตา ไม่มีอะไรขยับ ปลอดภัย 100%

- [ ] ภาพขึ้น ไม่ดำ ไม่ค้าง
- [ ] เอาตุ๊กตาเข้าเฟรม → ขึ้นกรอบเขียว ชื่อถูกตัว
- [ ] เอา**ถุงพลาสติก/ผ้าห่ม/หมอน**เข้าเฟรม → ไม่ควรขึ้นกรอบแล้ว (train-5 แก้ไปแล้ว)
- [ ] ลองระยะไกลสุดที่จะใช้จริง — ยังจับติดไหม

## 3️⃣ `3-เล็งแมนนวล.bat` — กล้อง + Arduino พร้อมกัน ⭐ **ขั้นที่ใช้เวลานานสุด**
ตรงนี้คือหัวใจ ทำ 4 อย่างตามลำดับ **ห้ามข้าม**

### 3.1 ทิศทาง (`AIM_SIGN` / `AIM_TILT_SIGN`) — ทำก่อนเสมอ
เล็งกล้องไปที่วัตถุนิ่งๆ แล้ว:

| กด | ภาพต้องเลื่อนไปทาง | ถ้าเลื่อนตรงข้าม |
|---|---|---|
| `d` (pan +) | **ซ้าย ←** | แก้ `AIM_SIGN = -1` |
| `s` (tilt −) | **ขึ้น ↑** | แก้ `AIM_TILT_SIGN = -1` |

(บนจอมีบรรทัดเตือนไว้ให้แล้ว ไม่ต้องจำ)
⚠️ **ผิดข้อนี้ = ป้อมจะหมุนหนีเป้าไปชนลิมิตตอนออโต้** และจะไปโผล่เป็นอาการอื่นที่หาสาเหตุไม่เจอ
แก้แล้วต้อง **ปิดโปรแกรมเปิดใหม่** (ค่าอ่านตอนเริ่ม)

### 3.2 วัด slop ของ servo
กด `b` → ป้อมหมุน +5° แล้วกลับ −5° ที่เดิม
**ภาพกลับมาจุดเดิมเป๊ะไหม?** ถ้าเลื่อนไปหลายพิกเซล = servo มีระยะฟรี (backlash)
→ ค่านั้นคือ**เพดานความแม่น** ต้องตั้ง `AIM_DEADBAND_PX` ให้ ≥ ค่านี้ ไม่งั้นป้อมจะส่ายในเขต slop ไม่จบ

### 3.3 ยิงจริง หา "จุดตกจริง"
1. เล็งด้วยมือให้กากบาทเขียวทับกลางตุ๊กตา
2. กด `f` → รอจอขึ้น **`>>> DROP THE BALL NOW <<<`** (มีนับถอยหลัง) → หย่อนลูก
3. ดูว่า**ลูกไปโดนตรงไหน**เทียบกากบาท
4. ยิงซ้ำ **5 นัด** ที่ระยะเดิม — จุดตกต้องเกาะกลุ่ม ถ้ากระจายมั่ว แปลว่าแรงไม่คงที่ (ล้อยังไม่นิ่งตอนหย่อน / ไฟตก) **หยุดแก้ตรงนี้ก่อน อย่าไปตั้ง zero**

### 3.4 ตั้ง `SCOPE_ZERO_OFFSET_PX` — ⚠️ ทำท้ายสุดเท่านั้น
กลุ่มกระสุนนิ่งแล้วค่อยทำ: กด `i`/`j`/`k`/`l` เลื่อนกากบาทไปทับ**จุดที่ลูกโดนจริง**
→ กด `p` เพื่อพิมพ์ค่าลง console → **copy ไปวางใน `src/config.py`** (ไม่วางไว้ = หายตอนปิดโปรแกรม)

### 3.5 🔴 เช็คสมมติฐาน "วิถีแบน" — อย่าลืมข้อนี้
ทั้งระบบวางอยู่บนความเชื่อว่า **zero จุดเดียวใช้ได้ทุกระยะ** ซึ่งยังไม่เคยพิสูจน์
→ ตั้ง zero ที่ระยะกลางแล้ว **ไปยิงใกล้สุด (1.5 ม.) กับไกลสุด (2.4 ม.) ทันที**
- โดนทั้งคู่ = สมมติฐานผ่าน ✅ จบ
- **ใกล้โดนแต่ไกลตกต่ำ** = วิถีไม่แบนพอ ต้องชดเชยมุมเงยตามระยะ (ranging กลับเข้าเกม) **บอกผมทันที**

## 4️⃣ `4-ออโต้วันแข่ง.bat` — ของจริง
เข้าขั้นนี้**หลัง 3 ผ่านหมดแล้วเท่านั้น**

- คลิกที่ตุ๊กตา → ป้อมหันเอง จนขึ้น `>> LOCKED · ON ZERO · F TO FIRE <<`
- คลิกขวา = ยกเลิก | คลิกที่ว่าง = เล็งพิกเซลนั้น (สำรองตอนโมเดลไม่เห็น)
- `F` = ยิง (จอบอกจังหวะหย่อนลูกเหมือนขั้น 3)

| อาการ | แก้ |
|---|---|
| ป้อม**ส่าย**รอบเป้าไม่นิ่ง | ลด `AIM_KP` (0.03 → 0.02) |
| ป้อม**คลานช้า** จน timeout 12 วิ | เพิ่ม `AIM_KP` (→ 0.04 **ห้ามเกิน 0.041**) |
| หมุนหนีเป้า | ทิศผิด — กลับไปข้อ 3.1 |
| ล็อกแล้วเด้งหลุดบ่อย | เพิ่ม `AIM_DEADBAND_PX` |

## ถ้าอะไรพัง — เช็คตามนี้ก่อนทัก

| อาการ | มักเป็นเพราะ |
|---|---|
| จอดำ / ไม่มีภาพ | จอ iPhone ล็อก หรือ Camo ไม่ได้อยู่หน้าสุด → ปลุกมือถือ |
| หา Arduino ไม่เจอ | Arduino IDE / Serial Monitor เปิดค้างอยู่ (จองพอร์ตไว้) → ปิดให้หมด |
| ป้อมไม่ขยับแต่ไม่ error | ไฟ servo ไม่เข้า (USB อย่างเดียวไม่พอ) |
| หน้าต่างดำเด้งแล้วหายทันที | ไม่มีทางเกิดแล้ว — ทุก `.bat` มี `pause` ค้างข้อความไว้ให้อ่าน |
